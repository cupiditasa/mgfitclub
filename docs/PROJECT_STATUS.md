# وضعیت خروجی GitHub — 2026-09-12

این خروجی از آخرین پوشهٔ `current/` ساخته شده و شامل اصلاحات رابط کاربری داشبوردها، orbit مربی/مدیریت، PWA، اتصال فرانت‌اند به API، صفحهٔ مجله و رسانه‌های آن است.

## اجزای موجود

- صفحات ورود، سایت اصلی، اپلیکیشن و داشبوردهای ورزشکار، مربی، مدیریت، منشی و پشتیبان.
- تم مشترک و پس‌زمینهٔ ویدیویی برند برای صفحات داشبورد.
- صفحهٔ مجله با SEO، تصاویر، حرکت‌های تعاملی و صفحه‌های ویدیویی.
- `backend/worker.js` برای احراز هویت، نقش‌ها، session، برنامه‌ها، پیام‌ها، تراکنش‌ها و endpointهای مدیریتی.
- `backend/schema.sql` و `backend/migrations/001-runtime.sql`.
- تست‌های API در `backend/test/worker.test.mjs`.

## موارد امنیتی

- پوشهٔ `توکن Cloudflare` و `restore_tmp` عمداً در این خروجی نیستند.
- کلیدهای SMS، OTP و Cloudflare فقط باید به‌صورت Secret/Binding روی Worker تنظیم شوند.
- manifestهای خروجی در `docs/` مسیر، اندازه و SHA-256 فایل‌ها را ثبت کرده‌اند.

## وضعیت قابل ادامه

برای تغییرات بعدی، همین بسته را به‌عنوان snapshot کامل GitHub نگه دارید و قبل از انتشار نسخهٔ جدید، تست‌های بک‌اند و لینک‌های رسانه‌ای مجله را دوباره بررسی کنید.
