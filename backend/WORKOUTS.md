# برنامه تمرینی — تغییرات محلی ۲۰۲۶-۱۰-۰۵

دیتابیس و Worker این بخش در ۲۰۲۶-۱۰-۰۵ فعال شدند. ورود، پیامک و تردد تغییری نکرده‌اند. انتشار فرانت‌اند از مسیر GitHub Pages انجام می‌شود.

## انتشار بعد از تأیید

1. از D1 نسخه پشتیبان بگیرید؛ مهاجرت‌های قبلی باید موجود باشند.
2. به ترتیب `migrations/008-workouts.sql` و `migrations/009-exercise-catalog.sql` را اعمال کنید. هر دو افزایشی‌اند؛ جداول برنامه قدیمی، ورود و تردد دست‌نخورده می‌مانند.
3. Worker باید همراه تمام ماژول‌های قبلی و **workouts.js و workout-domain.js** منتشر شود. ابزار انتشار قدیمی با فهرست ثابت ماژول‌ها باید پیش از استفاده بازبینی شود.
4. متغیر غیرمحرمانه `WORKOUTS_ENABLED=true` را با حفظ سایر متغیرها و secrets تنظیم کنید. بدون آن مسیرهای جدید عمداً 503 می‌دهند.
5. پس از تست API، فایل‌های فرانت‌اند پایین و service worker منتشر شوند. فقط آپلود HTML روی GitHub کافی نیست.
6. با دو حساب واقعی مربی/ورزشکار و مدیر همان باشگاه، ذخیره، ارسال، دریافت و گزارش را تست کنید. برای ارسال، مربی باید club_id تأییدشده داشته باشد.

بازگشت امن: feature flag را غیرفعال کنید؛ جداول یا نسخه‌های ارسالی را حذف نکنید. در صورت لزوم فایل‌های فرانت‌اند قبلی را برگردانید.

## فایل‌های فرانت‌اند

- coach.html: ساخت/ویرایش برنامه هفتگی، شنبه پیش‌فرض.
- coach-programs.html: لیست واقعی قالب‌ها، ارسال و بایگانی.
- workout-view.html: انتخاب برنامه دریافتی، روز تهران و تایمر.
- exercise-library.html: بانک مشترک حرکات؛ فعلاً جدا از صفحه نهایی آموزش.
- workout-log.html: گزارش ارسالی‌ها، با محدودیت دسترسی سمت سرور.
- workouts.js، workouts.css، workout-domain.js.
- access-center.html/js: تب برنامه‌های ارسالی مدیر/پشتیبان.
- education.html: لینک بانک مشترک؛ طرح فعلی حفظ شده.
- coach-food.html: امکانات محلی غذایی قبلی جدا شده‌اند؛ نه به API برنامه تمرینی مهاجرت کرده‌اند و نه ارسال واقعی دارند. داده localStorage قبلی حذف نشده.
- sw.js: نسخه کش جدید.

## قواعد داده

- ۱۵۵ نام از فایل ارائه‌شده وارد شده‌اند؛ متن‌های راهنمای ورزشی و رسانه‌های نمونه وارد نشده‌اند.
- ۱۵ گروه بدنی (شامل گروه‌های کلی منبع و گزینه‌های جزئی‌تر) و ۴ سبک جداگانه. گروه‌بندی علمی خودکار انجام نشده است.
- نام یکتا با NFKC، یکسان‌سازی ی/ک، ارقام و حذف فاصله/علائم؛ نام‌های مترادف با واژه‌های متفاوت نیاز به بازبینی انسانی دارند.
- ۷ روز و حداکثر ۲۰ حرکت در هر روز. ست ۱–۵۰، تکرار ۱–۱۰۰۰، مدت هر ست ۱–۳۶۰۰ ثانیه و استراحت ۰–۳۶۰۰.
- زمان = مجموع (ست × مدت اجرا + (ست − ۱) × استراحت بین ست‌ها) + استراحت بین حرکات، بدون استراحت بعد از حرکت آخر.
- هر ارسال یک snapshot مستقل و غیرقابل تغییر است؛ ویرایش قالب فقط نسخه‌های آینده را عوض می‌کند.
- دریافت‌کننده فاقد باشگاه قابل انتخاب است؛ دریافت‌کننده با باشگاه متفاوت رد می‌شود. باشگاه گزارش از عضویت مربی در سرور تعیین می‌شود.
- افزودن ویدیو فعلاً API ثبت metadata برای فایل‌های HTTPS همان دامنه است، نه آپلود فایل. صفحه نهایی آموزش/بارگذاری ویدیو پس از دریافت طرح کاربر تکمیل می‌شود.
- این نسخه آنلاین است؛ کش service worker جای دیتابیس یا مجوز آفلاین را نمی‌گیرد. تایمر در همان صفحه با ساعت monotonic کار می‌کند؛ reload تایمر را از نو شروع می‌کند.

## مسیرهای API

همه زیر /api/workouts و نیازمند ورود و حساب تأییدشده‌اند:

- GET catalog / POST exercises
- GET و POST exercises/:id/videos
- GET و POST templates
- GET و PATCH templates/:id
- POST templates/:id/send و templates/:id/archive
- GET deliveries و deliveries/:id

POST ساخت و ارسال نیازمند requestKey یکتا هستند؛ PATCH و ارسال نیازمند revision فعلی‌اند.
